dsh 邮件助手

dsh 是一个运行在开发者本人电脑上的个人 AI 助手。本应用通过 Gmail API，让该助手在用户授权后完成以下操作：

  • 按关键词或 Gmail 搜索语法查找邮件；
  • 读取邮件正文和会话内容，生成摘要；
  • 在用户的 Gmail 草稿箱中创建回复草稿（不会自动发送，需用户本人检查并点击发送）。

本应用仅供开发者个人使用，所有数据都在本地处理，不会上传到任何第三方服务器。

隐私政策 · 服务条款

dsh Mail Assistant is a personal, locally-run AI assistant. With the user's consent it uses the Gmail API to search and read messages and to create draft replies (never sent automatically). It is for the developer's personal use only; data is processed locally.
