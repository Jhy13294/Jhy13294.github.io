隐私政策

生效日期：2026 年 11 月

收集哪些数据

在你授权后，本应用通过 Gmail API 读取你的邮件内容和元数据（发件人、主题、日期、标签），并可在你的草稿箱中创建草稿。

如何使用

这些数据只用于在你本人的电脑上，由你的个人 AI 助手完成你发起的邮件查询、摘要和起草回复。

存储与共享

OAuth 令牌只保存在你本地电脑上。本应用不运营任何服务器，不会出售、转让或与第三方共享你的 Gmail 数据，也不会把数据用于广告。

本应用对 Google API 所获信息的使用和传输，遵守 Google API Services User Data Policy，包括其中的 Limited Use（有限使用）要求。

撤销授权

你可以随时在 Google 账号权限页面 撤销本应用的访问权限，并删除本地的 token 文件。
